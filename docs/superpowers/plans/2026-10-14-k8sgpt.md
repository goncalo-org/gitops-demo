# K8sGPT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the K8sGPT operator in both kind clusters through Argo CD, explaining findings with Ollama on the Mac, with findings visible as Result CRs and in Grafana.

**Architecture:** One ApplicationSet (cluster generator, gated by branch like Alloy) deploys the `k8sgpt-operator` chart and a `K8sGPT` custom resource from `platform/k8sgpt/`. The resource uses the `localai` backend against Ollama's OpenAI-compatible API at `http://192.168.5.2:11434/v1`; Colima maps 192.168.5.2 to the Mac's loopback. The operator logs each Result, and Alloy ships those logs to Loki for a Grafana panel.

**Tech Stack:** Argo CD ApplicationSets, Helm (`k8sgpt/k8sgpt-operator` 0.2.29), K8sGPT v0.4.40, Ollama (`llama3.2:3b`), Grafana/Loki, bash.

**Spec:** `docs/superpowers/specs/2026-10-14-k8sgpt-design.md`

# K8sGPT in this cluster: built-in analyzers, explained by Ollama on the Mac.
# 192.168.5.2 is Colima's address for the Mac's loopback, so Ollama stays on 127.0.0.1.

apiVersion: core.k8sgpt.ai/v1alpha1

    backend: localai
    baseUrl: http://192.168.5.2:11434/v1
    model: llama3.2:3b

- [ ] **Step 1: Add `check_k8sgpt` to `scripts/smoke-test.sh`.** Add `PROD=kind-prod` under `DEV=kind-dev`. Put this function after `check_data`:

```bash
# check_k8sgpt: a pod with a nonexistent image in prod must get a K8sGPT Result
# with an AI explanation (details) within 3 minutes. The namespace isn't managed by Argo CD.
check_k8sgpt() {
  local ns=k8sgpt-smoke deadline=$((SECONDS + 180)) sel found="" details=""
  sel='{.items[?(@.spec.name=="k8sgpt-smoke/broken")]'
  kubectl --context "$PROD" delete namespace "$ns" --ignore-not-found >/dev/null
  trap 'kubectl --context "$PROD" delete namespace k8sgpt-smoke --ignore-not-found --wait=false >/dev/null 2>&1' EXIT
  kubectl --context "$PROD" create namespace "$ns" >/dev/null
  kubectl --context "$PROD" -n "$ns" run broken --image=ghcr.io/stefanprodan/podinfo:0.0.0-missing >/dev/null
  while (( SECONDS < deadline )); do
    found=$(kubectl --context "$PROD" -n k8sgpt get results.core.k8sgpt.ai -o jsonpath="$sel.metadata.name}" 2>/dev/null || true)
    details=$(kubectl --context "$PROD" -n k8sgpt get results.core.k8sgpt.ai -o jsonpath="$sel.spec.details}" 2>/dev/null || true)
    [[ -n "$found" && -n "${details//[[:space:]]/}" ]] && break
    sleep 10
  done
  if [[ -z "$found" ]]; then
    echo "FAIL k8sgpt-prod: no Result for $ns/broken (analyzer path)"; failures=$((failures + 1))
  elif [[ -z "${details//[[:space:]]/}" ]]; then
    echo "FAIL k8sgpt-prod: Result has no explanation (is Ollama reachable?)"; failures=$((failures + 1))
  else
    echo "ok   k8sgpt-prod: ${details:0:80}..."
  fi
}
```

Call it after the `check_data traces-prod ...` line:
